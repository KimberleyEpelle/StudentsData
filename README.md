# 📊 Student Metrics Visualization Dashboard

**Description:**  
An interactive Excel-based dashboard designed to visualize and analyze student performance metrics.  
The project demonstrates strong analytical and reporting skills — transforming raw data into meaningful insights using data visualization and formula-based automation.

---

## ⚙️ Features
- Displays key academic metrics such as grades, attendance, and performance trends  
- Uses dynamic **Excel charts**, **pivot tables**, and **interactive filters**  
- Provides a clean interface for quick data-driven insights  

---

## 🧠 Tools & Techniques
- **Software:** Microsoft Excel  
- **Key Skills:** Data cleaning, pivot tables, dashboards, charts, KPIs  
- **Functions Used:** VLOOKUP, INDEX-MATCH, IF statements, conditional formatting  

---

## 💡 Learning Outcome
- Strengthened ability to communicate insights visually and effectively  
- Improved understanding of **data storytelling** and dashboard design principles
